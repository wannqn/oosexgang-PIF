# oosexgang PIF data

`pif.json` and `keybox.xml` are consumed directly by the file-based updater. `info.txt` is a JSON manifest (format 1) with SHA-256 hashes of both files. Update all three together in one commit.

Keybox material is public in this branch with the owner's explicit authorization. No APK or Java source is included. The legacy `pif-apk` branch is separate.
